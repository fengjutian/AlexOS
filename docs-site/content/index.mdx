## 最短路径

```powershell
cargo build --release --locked
.\target\release\alex.exe create .\my-app --id com.example.my_app
.\target\release\alex.exe dev .\my-app
```

开发窗口打开后，修改 `my-app/frontend/` 下的文件即可看到刷新结果。
