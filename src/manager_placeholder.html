Alex OS App Manager

Phase 1.4 backend online. UI ships in Phase 1.5.

This is the system-level App Manager surface. The Rust backend (AppManager trait, ManagerRouter, and RuntimeSupervisor) is wired up and reachable via alex://system/app-manager/ with the alex://system/app-manager source identity.

Try a manager call from the devtools console:

await alex.invoke("manager.list_apps")

Phase 1.5 will replace this placeholder with a real React + TypeScript UI: app list, detail, install, trust, permission editor.
